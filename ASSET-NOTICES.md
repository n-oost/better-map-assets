# Asset provenance and notices

This private snapshot preserves existing Better Map imagery for development. It is not a declaration that all included imagery is licensed under the plugin's software license.

RuneScape/Old School RuneScape game artwork and underlying game content belong to Jagex. Some existing map inputs may originate from OSRS Wiki map services. Their applicable attribution and redistribution terms must be reviewed before public distribution.

The unified map-0 collection was generated using Better Map tooling based on RuneLite's cache renderer. Other map IDs lack a complete source ledger in the current local collection. Publication metadata preserves the original generation counters, including a misleading `regionsFailedToDecrypt` label: the 2026-09-27 audit found 426 successfully decoded empty object lists and zero decode errors. See `INVESTIGATION.md` for the scope of that check.

No raw game-cache archives, authentication credentials, player data, or XTEA key files are included. The companion dataset hashes in metadata are identifiers only; datasets remain in the plugin repository for this phase.

The publisher script is original project tooling; asset rights remain separate from tooling rights.
